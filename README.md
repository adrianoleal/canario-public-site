# Leal Assistant Canário — site público

Site institucional estático do assistente pessoal Canário, para transparência sobre Google OAuth.

- index.html — apresentação
- canario-privacidade/index.html — política de privacidade
- canario-termos/index.html — termos de uso

Publicação estática. Sem runtime de bot, tokens, OAuth secrets, analytics, formulários ou dados de usuários.

**Fronteira:** o aplicativo propriamente dito roda em infraestrutura privada; este repositório apenas hospeda texto informativo. Atualizações de privacidade devem acompanhar mudanças reais no processamento de dados.
